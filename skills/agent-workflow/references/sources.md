## User-Customized Rules

PRD/Spec/Design writing skills, directory-based Change material sets, target-to-current Spec merging, on-demand ADRs, date naming, automatic archival, draft/approved/accepted states and main-agent closeout responsibilities come from the local workflow design. They are not universal upstream Matt skills conventions. Legacy single-file Changes remain supported; the former document checker and its report requirement have been removed.

Document simplification means reducing duplication and default loading scope, not omitting consequential contracts. Cross-document authority, states and acceptance responsibilities are maintained in change-planning's document contract. Local supporting skills [prd-writing](../../prd-writing/SKILL.md), [spec-writing](../../spec-writing/SKILL.md) and [design-writing](../../design-writing/SKILL.md) own their document methods; prd-writing selects focused clarification when needed, and design-writing selects domain-modeling and codebase-design for specialist work. Planning, execution and review link to those owners. All selected skills live in this project's `.agents/skills/` collection; execution does not depend on a local path to the upstream repository.

The current runtime supplies execution mechanisms; the user maintains models, plugins, and subagent roles. Shared skills govern authorization, responsibilities, handoffs, and acceptance without binding to a particular subagent plugin. This collection does not modify the old team-workflow or automatically install or configure upstream trackers.
